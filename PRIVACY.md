# AppForge Privacy Policy

Last updated: September 8, 2026

AppForge is an open-source application selection and installation project.

## Data collection

AppForge does not operate an AppForge account service and does not intentionally collect, store, sell, or transmit personal information to an AppForge-controlled server.

The AppForge website runs in the user's browser. The AppForge installer accesses networked systems only when requested by the user as part of selecting, downloading, opening an official download page, or installing software.

## Third-party services

AppForge may contact third-party services that are necessary for its user-requested functionality, including GitHub Pages for hosting, package managers such as Windows Package Manager (Winget), Flatpak/Flathub, or Homebrew where applicable, official software vendor websites, and services used to retrieve application icons. Those third parties have their own privacy policies and terms.

## Installation behavior

AppForge installs only applications selected by the user. Installing applications can cause those third-party applications and package services to communicate with their own network services under their respective privacy policies.

## Code signing

AppForge is applying for free open-source code signing provided by SignPath.io, certificate by SignPath Foundation. No release is represented as SignPath-signed until the project has been accepted and the release has actually received a valid signature.
