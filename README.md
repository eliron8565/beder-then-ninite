# AppForge

A modern Ninite-inspired Windows app selector.

## Features

- Searchable app catalog
- Category filters
- Select multiple apps
- Generate a ready-to-paste Windows Winget install command
- Popular-app quick selection
- Responsive desktop/mobile UI
- Dark/light theme
- No download mirrors or bundled installers

## Run locally

Open `index.html` in a browser.

## Publish with GitHub Pages

In the repository on GitHub, open **Settings → Pages**, choose **Deploy from a branch**, select the `main` branch and `/ (root)`, then save.

The site is independent and is not affiliated with Ninite or Microsoft.
